LSTM · Residential electricity forecasting

Hourly consumption for Bukit Mahkota, Bangi, modelled and explained.

A 2-layer LSTM trained on a year of hourly meter readings and matching weather data — running entirely in your browser via TensorFlow.js, no server involved. This dashboard breaks down the consumption pattern, what the model actually leans on to predict it, and how accurate it is on data it never trained on.
